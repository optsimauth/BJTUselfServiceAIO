## 已落实的改造

- 统一品牌蓝的 tonalSpot 浅深配色，降低重复服务图标色块的饱和度；卡片、导航、输入、次按钮、文字统一主题语义。
- 导航由任意 720/1100 改为 600/1200；实际点击区域测试发现展开侧栏高度只有 44，已加内边距修到至少 48。
- 服务页去掉占据首屏的重复大标题，按学业/校园分组；宽内容区排两列，手机与大字号单列。
- 首页先显示今日安排和课程，再显示账户状态。长课程名称、地点和教师可换行；三项状态在大字号下竖排。登录状态提示条以最小高度代替固定高度，允许大字号自然换行。
- 登录表单宽度集中为 440；主按钮支持长文案与大字号，加载时给文字反馈并防止重复提交。
- 复用现有 PageWidth，将成绩、考试、作业、课件、设置正文上限设为 840，避免桌面长行拉伸。
- 设置页主题选择放在标题下面；课件、邮件搜索输入补常驻标签。
- 课件与邮箱自定义高度动画尊重系统减少动画设置。课件减少动画模式直接展示内容，避免零时长 AnimatedSize 的布局异常；成绩回顶在该模式下用 jumpTo。
- 对比度测试纠正为包含 0.05 偏移的 WCAG 公式，补黑白 21:1 与同色 1:1 的校准断言。
